# Oil Management v3.8.3 — малый промысел

Базируется на v3.8.2. Прежний интерфейс, без 3D и отдельного режима «с нуля».

- Новая карьера: одна действующая скважина, один РВС, один сборный узел, один вагончик.
- Старый автоматически созданный кадровый реестр крупного предприятия заменяется 12 начальными должностями. Новые сотрудники появляются в реестре только после завершения игрового подбора.
- Структура предприятия состоит из трёх небольших функциональных групп. Департаменты большой компании не создаются автоматически.
- Вместо больших складских остатков — небольшой набор ЗИП и оборудования одной скважины.
- Вместо ДНС-1/ДНС-2/ЦППН с огромными мощностями — упрощённая малая технологическая цепочка (производственные узлы остаются совместимыми со старым движком).
- Финансовый ФОТ остаётся единым и равен 3,6 млн ₸/мес. на старте. Существующие старые карьеры не мигрируют в малый режим.
- Действующая механика роста штата и вахтового посёлка сохранена.

**Ограничения:** технологическая модель ЦППН и некоторые экраны отчётности по-прежнему используют упрощённые механизмы большого предприятия. Крупные отчёты, рейтинги и логика нескольких цехов требуют дальнейшего выделения по масштабу компании. Параметры мощностей, окладов и затрат — условные игровые значения.

**Тесты:** `python build.py && node tests/module-test.js && node tests/smoke-test.js && node tests/economics-test.js`.
