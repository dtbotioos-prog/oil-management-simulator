# Oil Management v3.9.3 — инженерная инфраструктура

Энергетическая цепочка: внешняя сеть + ГТЭС -> ограничение пропускной способности РП/КТП -> нагрузка промысловых объектов -> питание насосных установок. При дефиците мощности часть работающих скважин исключается из фактической добычи; статус не заменяется фиктивной поломкой. По мере роста фонда скважин увеличивается нагрузка. Отдельно строятся ГТЭС, РП, КТП, ВЛ, резервная ДЭС.

Коммунальная цепочка: водоснабжение -> бытовые объекты -> канализационная насосная станция -> КОС. Показываются потребность и доступная производительность в м³/сут. Для столовой и общежития предусмотрен контроль дефицита мощностей воды и очистки стоков.

Все здания строятся при наличии денег, вводятся после игровых сроков, имеют капзатраты и содержание. Коэффициенты условные игровые, не заменяют проектные расчёты, требования ПБ, санитарных норм или экологические разрешения. В будущих версиях нужны независимые энергосхемы скважин, резервирование, отказоустойчивость, баланс ППД/подготовки нефти, нормативы очистки и разрешения на сброс.
