# Oil Management v3.8.5 — ДЧС и экология

Добавлен модуль государственных проверок для новой карьеры малого промысла:
- Предписания ДЧС и экологические нарушения;
- Условные игровые экологические штрафы;
- Финансирование устранения несоответствий с задержкой в игровых днях;
- Отдельные проводки в журнале экономики, расходы вычитаются из денежных средств;
- Журнал событий и ручные учебные проверки;
- Автоматическая проверка примерно раз в три игровых месяца (с вероятностью выявления);
- Сохранение в localStorage вместе с карьерой.

Все суммы условные (млн тенге), не являются официальными санкциями РК. В старых сохранениях крупного предприятия новая механика не включается.

Проверено: сборка 30 модулей, smoke-test, module-test, economics-test. Полный браузерный сценарий не проверен.
