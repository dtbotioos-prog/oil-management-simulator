# Oil Management v3.8.4 — малый промысел: отчётность и рейтинг

Изменения применяются только к сохранениям новой карьеры (`s.small`).
- План/факт выводится по реально существующим ГУ, а не по фиктивным цехам.
- Для малого промысла разрешено корректировать годовой план ниже 12 000 т с основанием.
- Техническая сводка отражает реальный фонд скважин и существующие резервуары.
- Рейтинг учитывает выполнение собственного плана, а не абсолютные объёмы крупных компаний; до строительства вахтового посёлка нет штрафа за его отсутствие.
- Бытовое обеспечение до строительства посёлка показано без фиктивных общежитий.
- Старые карьеры остаются на прежних алгоритмах.

Проверено: сборка, node --check, smoke-test, module-test, economics-test.
Не проверено: полный сценарий игры в браузере и сохранения после длительной симуляции.
