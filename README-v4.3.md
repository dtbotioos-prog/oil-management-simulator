# Oil Management v4.3 Alpha — геология, бурение и логистика

Обновление отдельного режима `start-from-zero.html`.

- Геологический разрез и индикатор проходки разведочной скважины по игровым дням.
- Буровая вышка и индикатор прогресса в 3D-мнемосхеме.
- Договор на транспортировку и приём нефти — необходим для отгрузки.
- Учитываются расходы на вывоз нефти и накопленный отгруженный объём.
- При заполнении буферной ёмкости добыча останавливается до отгрузки.
- Действующая карьера остаётся отдельным режимом.

Условные цены, разрез и темп бурения являются игровой моделью. Это не полноценный геологический симулятор и не фактический регламент недропользования.
