# Архитектура v2.4

`src/` — исходные разделы, которые собираются в один JS-файл для сохранения области видимости старого движка.
`build.json` — единственный источник порядка модулей.
`build.py` — сборщик без внешних зависимостей.
`js/core/game.js` — готовый браузерный скрипт.
`tests/` — smoke и проверка равенства собранного кода исходным модулям.

Дальнейшие этапы: независимые интерфейсы состояния; выделение моделей добычи и экономики; единый ledger; регрессионные тесты с фиксированными сценариями; браузерное тестирование.
