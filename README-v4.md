# Oil Management v4.0 — первый этап «С нуля»

Откройте `start-from-zero.html` (на GitHub Pages: `/oil-management-simulator/start-from-zero.html`). На основном `index.html` есть ссылка на этот режим. Старый режим v3.7.4 сохранён, его localStorage не затрагивается.

Реализовано: нулевая стартовая база; регистрация компании и капитал; три вымышленных участка; юрист как обязательное условие; процедура получения права на недропользование; геолог и геофизика; найм специалистов; дорога, вагончики, ДЭС, вода, связь; проекты с продолжительностью, зависимостями и расходами; ежемесячные зарплаты и содержание; разведочная скважина с риском отсутствия притока; отдельное автосохранение и экспорт JSON.

Ограничения первого этапа: цены и сроки условные, юридические процедуры упрощены; нет моделирования налогов, долгов, лицензий по видам деятельности и полного календаря разрешений; промышленная добыча ещё не связана со старым движком. Покупка участка не означает покупку земли: модель представляет получение права недропользования.

Тест: `node --check js/greenfield.js`, `node tests/smoke-test.js`, `node tests/module-test.js`.
