# Oil Management v1.2 — сохранение и загрузка

Основа: текущий index.html версии v1.1. Новая панель внизу экрана:
- Сохранить: записывает текущее состояние в localStorage.
- Скачать JSON: переносимый файл карьеры.
- Загрузить JSON: восстановление карьеры из файла, с проверкой структуры и подтверждением.
- Резервная копия: восстановление состояния до последнего импорта.

Автосохранение предыдущей версии сохраняется. Используется прежний ключ localStorage `oil-management-v01`.

Важно: резервная копия в браузере хранит только предыдущее состояние перед импортом. Для надёжного архива регулярно скачивайте JSON. Перед обновлением index.html сохраните копию старой версии.

Не включено в эту версию: расследования и автоматические обоснования увольнения; это отдельный следующий этап.
