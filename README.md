# Oil Management v0.7 — Производственная структура

## Обновление GitHub Pages
1. Сделайте резервную копию старого `index.html`.
2. Замените файл в корне репозитория `oil-management-simulator` на этот `index.html`.
3. Commit changes. Откройте сайт и обновите страницу.

## Новое
- Вкладка «Объекты · ГУ · скважины» с выбором ЦДНГ-1…4, ГУ и скважины.
- Индивидуальная карточка скважины и условный паспорт привода.
- Заказ ПРС/КРС со сроком и затратами, остановка/пуск, замена привода.
- Условные игровые производственные управления вместо названий реальных ПУ.
- Генератор вымышленных сотрудников с согласованными мужскими и женскими именами и фамилиями.
- Совместимость с прежним ключом localStorage `oil-management-v01`.

**Важно:** имена, должности, данные, сроки и стоимость — игровые; это не производственная документация. Часть старых сохранений может содержать ранее введённые пользователем имена, они не переписываются автоматически.
