# Oil Management v3.6.3 — постоянный номер места в верхней панели

На каждом игровом экране в верхней панели отображается текущее место № N / 100 и изменение ▲/▼ за последний игровой день. Индикатор обновляется при каждом игровом шаге. Нажатие открывает полный рейтинг и прокручивает страницу к таблице. На мобильных экранах индикатор занимает отдельную строку в верхней панели. Начало карьеры — 100-е место; дальнейшее движение зависит от игровых показателей.

Перед обновлением экспортируйте сохранение в JSON. Полное браузерное тестирование не проводилось.
