# Oil Management v2.3

Модульная файловая структура: HTML, отдельные CSS, JS, PWA. Функциональность v2.2 сохранена без переписывания игровой логики.

## GitHub Pages
Загрузите **всё содержимое архива**, включая папки `css` и `js`, в корень репозитория. Только `index.html` теперь недостаточно.

## Проверка
`node tests/smoke-test.js`

## Важно
Это первый этап структурной реорганизации. Полная декомпозиция бизнес-логики, тестирование игровых сценариев и унификация расчётов ещё впереди. Перед обновлением экспортируйте сохранение в JSON.
