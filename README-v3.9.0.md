# Oil Management v3.9.0 — найм и эффективность
Для новой карьеры малого нефтепромысла:
- Должности, подразделения, зарплаты и сроки подбора определяются автоматически по выбранной вакансии.
- После завершения подбора реальные должности появляются в кадровом реестре.
- Обеспеченность операторскими сменами влияет на фактическую добычу (в пределах 82–100% базового расчёта).
- Слесари влияют на показатель ремонтной обеспеченности; безопасность и экология постепенно зависят от профильных работников.
- Система рекомендует следующую вакансию исходя из числа действующих скважин.
- Увеличение ФОТ учитывается после приёма, подбор оплачивается отдельно.
- Режим крупного предприятия не изменяется.

Игровые коэффициенты условны, не являются нормами численности или отраслевыми стандартами.
Проверено: сборка, smoke-test, module-test, economics-test. Полный браузерный сценарий не проверен.
