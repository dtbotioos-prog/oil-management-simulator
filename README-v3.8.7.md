# Oil Management v3.8.7 — корректировка ремонта скважин

Для малой карьеры: устранён `undefined лет` (срок службы по умолчанию 12 лет); введены диагностика (2 млн ₸, 2 дня), ТО (3 млн ₸, 1 день), ПРС (28 млн ₸, 10 дней), КРС (105 млн ₸, 28 дней). ПРС и КРС ограничены состоянием скважины; повторный ремонт при активных работах запрещён. После окончания ремонта скважина остаётся остановленной до подтверждённого пуска. Автоматическое месячное старение дополнено небольшим износом; не запускает ремонт само по себе. Для старых сохранений крупной компании прежние механизмы остаются.
